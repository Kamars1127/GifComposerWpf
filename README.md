# GifComposerWpf
GIF 產生器。
---

# 主要功能
- 載入單張或多張圖片。
- 刪除單張或全部圖片。
- 上移或下移單張圖片。
- 從檔案總管將圖片拖進拖曳區塊。
- 預覽播放與暫停。
- 輸出尺寸、循環次數設定。
- 輸出檔案路徑。
- 產生 GIF。
